## 📌 Описание задания

Реализовать модульное тестирование Python-приложения с применением фреймворка **pytest** (аналог PHPUnit) и библиотеки **responses** (аналог Guzzle MockHandler). Протестировать класс регистрации на мастер-класс (поля: имя, дата рождения, тема, чекбокс «Материалы включены», радио «Формат участия») с реальной SQLite в памяти и с mock-объектом БД. Выполнить HTTP-тест с мокированием запроса к API регистрации. Обеспечить изоляцию тестовой среды через файл `.env.test`.

**Вариант:** «Регистрация на мастер-класс»

## ⚙️ Как запустить проект

1. Перейти в корень проекта (где находится `requirements.txt`):
    cd lab8
2. Установить зависимости:
   pip install -r requirements.txt
3. Запустить тесты:
```pytest -v```

4.  результат — 4 passed.
