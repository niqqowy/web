## 📌 Описание задания

Создать веб-приложение для регистрации на мастер-класс по художественным техникам с интеграцией публичного API Art Institute of Chicago.

Основные требования:

    Подключить внешние библиотеки с помощью Composer (Guzzle)

    Создать класс для работы с API

    Создать класс для сбора информации о пользователе

    Реализовать сохранение данных в сессию и cookies

    Получать и отображать данные из публичного API

    Реализовать кеширование API-ответов (штрафное задание)

---

## ⚙️ Как запустить проект

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/niqqowy/web
   cd web/lab4
2. Установить Composer и зависимости:
   # Инициализация Composer
   composer init

   # Установка Guzzle
   composer require guzzlehttp/guzzle
3. Запустить веб-серверы:
   php -S localhost:8000

4. Открыть в браузере (15 вариант):
```http://localhost:8000```

## 📂 Содержимое проекта

```composer.json ``` — Конфигурация Composer

```composer.lock``` — Зафиксированные версии зависимостей

```vendor/``` - Папка с установленными библиотеками

```index.php``` —  Главная страница с формой регистрации

```save.php``` — Обработчик формы и API запросов

```api.php``` — Эндпоинт для AJAX-обновления

```ApiClient.php``` — Класс для работы с API

```UserInfo.php``` — Класс для получения информации о пользователе

```api_cache.json``` — Файл кеша API-ответов

## ✅ Результат
Успешно установлен и настроен Composer с подключением библиотеки Guzzle для HTTP-запросов. Создан класс ApiClient для взаимодействия с публичным API Art Institute of Chicago. Создан класс UserInfo для сбора информации о пользователе (IP, User-Agent, время посещения). Реализована интеграция с API: данные о произведениях искусства успешно получаются, кешируются в файл api_cache.json и отображаются на странице. Реализована работа с cookie (last_submission) для хранения времени последней регистрации и сессиями для сохранения данных формы и API-ответов. Реализовано штрафное задание: кеширование API-ответов с временем жизни 5 минут, кнопка обновления данных через AJAX без перезагрузки страницы с использованием fetch, обработка ошибок API с выводом понятных сообщений пользователю.
