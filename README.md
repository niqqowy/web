## 📌 Описание задания

1) Модифицировать HTML-форму из ЛР-2 для отправки данных на сервер методом POST.
2) Создать PHP-обработчик с валидацией данных.
3) Реализовать сохранение данных в сессии.
4) Реализовать сохранение данных в файл.
5) Создать страницу просмотра всех сохранённых данных.
6) Добавить валидацию с выводом ошибок.
7) (*Штрафное задание*) Реализовать сохранение данных в Cookies.

## ⚙️ Как запустить проект

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/niqqowy/web/tree/lab3
   cd web
2. Запустить контейнеры:
```bash
docker-compose up -d --build
```
3. Открытие php страницы:
```http://localhost:8080```

4. Открытие HTML Формы (15 вариант):
```http://localhost:8080/form.html```

## 📂 Содержимое проекта

```docker-compose.yml``` — описание сервиса Nginx

```www/index.php``` — PHP-страница

```www/view.php``` — страница просмотра всех данных
