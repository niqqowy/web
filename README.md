## 📌 Описание задания

Создать веб-приложение для регистрации на мастер-класс. Вариант 15: имя, дата рождения, тема мастер-класса, чекбокс «Материалы включены», радио «Формат участия» (очный/онлайн). Данные сохраняются в MySQL, выводятся на отдельной странице.

---

## ⚙️ Как запустить проект

1. Клонировать репозиторий:
   git clone https://github.com/niqqowy/web
   cd web/lab5
2. Запустить контейнеры:
   docker-compose up -d --build
3. Открыть в браузере (15 вариант):
```Сайт: http://localhost:8080```
```Adminer: http://localhost:8081 (логин: lab5_user, пароль: lab5_pass, БД: lab5_db)```
