## 📌 Описание задания

Настроить непрерывную интеграцию и доставку (CI/CD) для PHP-приложения с использованием GitHub Actions и Docker. Реализовать автоматизированный pipeline, который при каждом пуше в репозиторий:

собирает Docker-образ с приложением
запускает контейнеры через docker-compose
устанавливает зависимости через Composer
запускает тесты PHPUnit внутри контейнера
корректно завершает работу контейнеров
логирует ошибки при падении тестов



---

## ⚙️ Как запустить проект

1. Клонировать репозиторий / создать структуру проекта:
   mkdir lab7 && cd lab7

2. Инициализировать Git и настроить удалённый репозиторий:
   git init
   
3. Запушить файлы в ветку (CI срабатывает на любой ветке):
```git add .```
```git commit -m "feat: add CI/CD pipeline"```
```git push -u origin main```
4. Проверить pipeline:
   Открыть GitHub → ваш репозиторий → вкладка Actions
   Дождаться завершения workflow PHP docker CI
   Убедиться, что все шаги прошли ✅
