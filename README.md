## 📌 Описание задания

Реализовать асинхронную обработку данных с использованием брокера сообщений RabbitMQ. Создать PHP-приложение с компонентами Producer (отправитель) и Consumer (обработчик), которые взаимодействуют через очередь сообщений. Данные о студентах (имя, группа, временная метка) отправляются в очередь при заполнении веб-формы и обрабатываются фоновым воркером с записью результатов в лог-файл.

**«Асинхронная обработка» (RabbitMQ)

---

## ⚙️ Как запустить проект

1. Клонировать репозиторий / создать структуру проекта:
   mkdir lab7 && cd lab7

2. Запустить контейнеры:
   docker-compose up -d --build
3. Открыть в браузере :
```Сайт: http://localhost:8080```
```Панель RabbitMQ: http://localhost:15672 (логин/пароль: guest/guest)```
4. Протестировать: заполнить форму на сайте → проверить консоль воркера → проверить файл processed.log
