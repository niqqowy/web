## 📌 Описание задания

Реализовать взаимодействие с Redis для хранения игровых данных: профили игроков, рекорды, топ-10 игроков, статистика. Использовать библиотеку `predis/predis` через Composer. Данные должны сохраняться и извлекаться через PHP-класс. Выполнить операции: запись/чтение, инкремент счета, получение топа игроков (Sorted Set).

**Вариант 15:** «Игры» (Redis)

---

## ⚙️ Как запустить проект

1. Клонировать репозиторий:
   git clone https://github.com/niqqowy/web
   cd web/lab6
2. Запустить контейнеры:
   docker-compose up -d --build
3. Открыть в браузере (15 вариант):
```Сайт: http://localhost:8080```

## ✅ Результат
Успешно настроены Docker-контейнеры: Nginx, PHP 8.2-FPM с Composer и Redis 7. Создан класс GameRedis с методами: setPlayerProfile, getPlayerProfile, addScore, getTopPlayers, getTotalPlayers, deletePlayer. Реализовано хранение профилей игроков в Hash, лидерборд в Sorted Set. На странице index.php отображается топ игроков и профиль выбранного игрока. Все операции с Redis выполняются через библиотеку Predis.
