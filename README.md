## ⚙️ Как запустить проект

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/niqqowy/web/tree/lab2
   cd web
2. Запустить контейнеры:
```bash
docker-compose up -d --build
```
3. Открытие php страницы:
```http://localhost:8080```

4. Открытие HTML Формы (15 вариант):
```http://localhost:8080/form.html```
